# Ваши тесты

Здесь лежат тесты, которые пишете вы — по одному файлу `test_solution.py` на каждую
задачу, которую вы выбрали. Структура зеркалирует `tasks/`:

```
tests/
  data_structures/
    stack_max/
      test_solution.py
  sorts/
    quick_sort/
      test_solution.py
```

Требования:

- минимум 5 тестов на задачу;
- импорт решения из `tasks.<раздел>.<задача>.solution`;
- граничные случаи (пустой вход, один элемент, дубликаты, отрицательные числа) —
  так же, как это делают эталонные тесты преподавателя в `tests_reference/`.

Эти тесты не заменяют эталонные — они показывают, что вы сами продумали кейсы,
на которых решение может сломаться. CI запускает и те, и другие.

Пример:

```python
from tasks.sorts.quick_sort.solution import quick_sort


def test_empty() -> None:
    assert quick_sort([]) == []
```
