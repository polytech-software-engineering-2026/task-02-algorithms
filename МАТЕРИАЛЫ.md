# Материалы к заданию

## Асимптотика и сложность алгоритмов

- [Big O Cheat Sheet](https://www.bigocheatsheet.com/) — таблица сложностей операций и сортировок
- [Wikipedia — Big O notation](https://en.wikipedia.org/wiki/Big_O_notation)

## Структуры данных

- [Real Python — Linked Lists in Python](https://realpython.com/linked-lists-python/) — односвязные и двусвязные списки на Python, ровно то, что нужно для `tasks_list`/`update_list`/`double_connected_node`
- [Real Python — Stacks and Queues](https://realpython.com/queue-in-python/) — стек как основа для `stack_max`

## Сортировки

- [Visualgo — Sorting](https://visualgo.net/en/sorting) — анимация bubble/insertion/merge/quick sort, полезно, если асимптотика не укладывается в голове
- [Wikipedia — Merge sort](https://en.wikipedia.org/wiki/Merge_sort)
- [Wikipedia — Quicksort](https://en.wikipedia.org/wiki/Quicksort) — раздел про выбор опорного элемента объясняет, почему наивный pivot даёт O(n²) на отсортированном массиве

## pytest

- [pytest — Get Started](https://docs.pytest.org/en/stable/getting-started.html)
- [pytest — How to parametrize fixtures and test functions](https://docs.pytest.org/en/stable/how-to/parametrize.html)
- [pytest-timeout — PyPI](https://pypi.org/project/pytest-timeout/) — как работает `@pytest.mark.timeout`, которым эталонные тесты ловят неверную асимптотику

## Инструменты качества кода

- [Ruff — документация](https://docs.astral.sh/ruff/) — линтер и форматтер, которым проверяется код
- [mypy — документация](https://mypy.readthedocs.io/en/stable/) — проверка типов
